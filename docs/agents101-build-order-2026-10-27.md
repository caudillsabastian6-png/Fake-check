# Agents 101 ideas → Real or Replica build order
Owner-approved Oct 27, 2026: use every workshop idea, translated to cards, not copied literally.
Playground/local only. No deploy, no tester send, no spend until owner reviews a preview.

## Already building (A–D, crew vote winner + owner all-in)
1. A — Checker as agent loop: identity → front tells → back tells → verdict, progress per step, Inconclusive when evidence lacking.
2. B — Verification layer inside verdict filing: checklist proven, every finding cites a recorded tell, Latch-style sign-off gate.
3. C — Evidence request / needs_input: missing identity, back, or slab cert stops and asks, never guesses.
4. D — Transparency console: timeline of what was seen, decided, and returned; bubbles are tells matching, not a percentage, not a grade.

## Leftovers, in build order (start after A–D lands, to avoid editing the same files in parallel)
5. Plan tool: show check steps before running, update plan as checklist changes.
6. Record_fact with exact evidence: each tell stored with measurement, reference, and photo/crop source — no finding without a recorded fact.
7. Flag do-not-use: other people's photos, private notes, and unpermissioned material flagged and excluded, never quoted as evidence.
8. Real slab check: cert + card inside, both required; cert alone never Genuine. Workshop placeholder (every signature consistent) is NOT acceptable here.
9. Saved / resumable / branch checks: a check can pause, resume, and re-run from its checklist without starting over.

## Gates before anything ships
- Core checker + verification tested on a real phone first.
- Canned tests pass: Alakazam vs itself = Likely Genuine, Alakazam vs Charizard = Inconclusive, front Genuine + fake back = Counterfeit.
- Owner reviews preview and approves deploy per item. No SAM-authenticates claim, no grade guess, no canned scan presented as real.
