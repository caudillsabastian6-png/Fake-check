How the pool is used (this is the answer to "why can't we use the whole pool"):
- YES, the whole pool is used — but only by tier. A submitted card is checked against the GENUINE side and the FAKE side separately, front-to-front and back-to-back. If it matches the genuine side on tells but is off in a way that matches a known fake tell, that is a flag, not a guess.
- Tiers A/B are the verdict-grade pool. Tier C (reference back designs, the unpaired Tier-1 back, the web genuine back, the web fake back) is research/reference only — it never decides a verdict by itself, because a reference design or a web example is not a verified same-card pair.
- Pending/unverified material is NEVER in A/B. That is the whole point of the split: one fake accidentally filed as genuine in the reference pool would make real cards look wrong and fake cards look right. So "whole pool" means whole VERIFIED pool, not every file on disk.
