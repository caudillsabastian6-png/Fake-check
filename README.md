# Real or Replica

A Fake Check for Pokémon cards.

Built for the Meta Global AI Developer Hackathon, Indie Dev Track.

## What it does

Real or Replica helps collectors spot counterfeit Pokémon cards. The hackathon-period build is One-Go Check: hold a real physical card to the phone, SAM 3.1 crops the card, the card is compared against a reference database, Muse Spark explains the verdict in plain words, and Muse Image draws a cauldron illustration around it. Art only, never a fake card photo.

Verdicts are honest and conservative: Likely Genuine, Likely Counterfeit, or Inconclusive. A photo-based opinion is never a guarantee, and an inconclusive result is never presented as a fake call.
